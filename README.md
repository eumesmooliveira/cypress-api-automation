Cypress API Automation
Projeto desenvolvido durante o Dia 2 do Bootcamp QA Automation da QAzando.

Objetivo
Configuração e automação de testes de API utilizando Cypress e JavaScript para validar cenários de busca de dispositivos, abordando tanto o caminho de sucesso quanto o de erro (validação de status code e corpo da resposta).

Tecnologias utilizadas
Cypress (Framework de automação)

JavaScript

Postman (Validação e suporte)

VS Code

Git/GitHub (Versionamento)

Como rodar o projeto
Clone este repositório:
git clone https://github.com/eumesmooliveira/cypress-api-automation.git

Instale as dependências:
npm install

Abra o Cypress:
npx cypress open
